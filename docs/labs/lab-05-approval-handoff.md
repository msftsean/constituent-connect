# Lab 05: Approval and cross-agency work

## Objective

Exercise human authority and least-necessary sharing across synthetic work
items.

## Path

1. Run **Cross-agency business move**.
2. Inspect the primary and secondary services.
3. Edit the draft without adding promises.
4. Approve it as the human reviewer.
5. Create the synthetic case.
6. Confirm separate synthetic work items share only the redacted summary.

## Check

Before approval, case creation is blocked. After approval, the audit trail
records the human decision and the handoff remains scoped.
