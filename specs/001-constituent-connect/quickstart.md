# Quickstart: Maryland Constituent Connect

## Participant outcome

Start with a local synthetic contact-center application, connect grounded Azure retrieval, configure an agency service, and demonstrate a safe intake-to-response workflow.

## Suggested lab path

1. Open the repository in GitHub Codespaces.
2. Run the local API and web experience.
3. Process routine, ambiguous, cross-agency, and emergency examples.
4. Inspect redaction, citations, route confidence, and the approval gate.
5. Replace mock retrieval with Azure AI Search.
6. Deploy the Azure resources with Azure Developer CLI.
7. Add one agency and three routes through configuration.
8. Run the evaluation suite.
9. Trigger an injection or unsafe-routing case and repair the failure.
10. Demonstrate the workflow, safety evidence, and agency extension.
