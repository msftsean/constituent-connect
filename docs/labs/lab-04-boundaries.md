# Lab 04: Ambiguity and emergency boundary

## Objective

Practice the two paths where the system must not guess or continue routine
processing.

## Path

1. Run **Ambiguous permit** and confirm the system asks a clarifying question.
2. Verify that no case can be created from the ambiguous result.
3. Run **Emergency boundary**.
4. Confirm emergency guidance, human escalation, no routine route, and the
   explicit **no dispatch** message.

## Check

The system does not infer an agency from an underspecified request and does
not dispatch emergency services. Real emergencies belong with 911 and the
appropriate human emergency path, not this workshop.
