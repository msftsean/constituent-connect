Constituent Connect architecture

This page is a static companion to the editable Drawio source. The diagram is the source of truth for the visual layout; this page keeps the safety boundaries readable without requiring diagram software.

Authority boundary: responses are drafts until human approval. Emergency handling provides guidance and escalation only. The system does not dispatch emergency services.

Listen

Normalize channel input, detect emergency language, minimize PII, and reject prompt injection.

Route

Use configured service ownership, confidence, disclosure, and escalation rules.

Respond

Use approved public knowledge to produce a cited draft or abstain when evidence is missing.

Human

Review, edit, approve, reroute, or escalate. Case creation is approval-gated.

Workshop implementation

The local workflow is transport-neutral and uses synthetic JSON configuration. The Azure-shaped components shown in the source diagram are future deployment placeholders, not a claim that this workshop is production-connected.
