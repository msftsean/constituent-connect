# Lab 00: Orientation and safety

## Objective

Understand the local-only workshop boundary before running the application.

## Path

1. Read the [fresh-user quickstart](../quickstart.md).
2. Review the [coach runbook](../coach-runbook.md).
3. Inspect the [architecture page](../architecture.html).
4. State the three non-negotiable boundaries:
   - all data is synthetic;
   - responses remain drafts until a human approves them;
   - emergency handling never dispatches services.

## Check

The participant can identify where approval occurs, where synthetic content is
configured, and why an emergency prompt exits routine routing.
