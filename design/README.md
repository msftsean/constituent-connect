# Constituent Connect Design Sources

- `constituent-connect-architecture.drawio` is the editable source of truth.
- Open it with drawio.com or the diagrams.net desktop application.
- Architecture nodes reference official Microsoft Fluent UI System Icons from the MIT-licensed `microsoft/fluentui-system-icons` repository.
- Every icon has a visible text label, so the diagram remains understandable if external icon loading is unavailable.
- Generated imagery is not required for this architecture. If future non-diagram imagery is added, use MAI Image 2.5 or MAI Image 2.6 and record prompt, model, date, intended use, and alt text in an asset manifest.
